# WebSocket Demo Endpoint

Get Auth required

Upgrades the connection to a WebSocket scoped to a demo Options Trading account. Requires a valid one-time password (OTP) from the OTP endpoint, passed as the otp query parameter. Use this channel to subscribe to market data, send trading instructions, and receive order and position updates for the demo account.

## Endpoint

Get `/trading/v1/options/ws/demo`

Base URL: `https://api.derivws.com`

## Request Schema

#### `query` — Required `object`

**Object Properties:**

  ##### `otp` — Required `string`

  One-time password generated by POST /trading/v1/options/accounts/{accountId}/otp

## Response Schema

#### `status` — Required `integer`

HTTP status code confirming the protocol switch.

#### `headers` — Required `object`

**Object Properties:**

  ##### `Upgrade` — Required `string`

  Confirms the connection was upgraded to the WebSocket protocol.

  ##### `Connection` — Required `string`

  Confirms the connection has been upgraded.

## Examples

### Request Example

```json
GET /trading/v1/options/ws/demo?otp=abc123xyz789

Query Parameters:
  - otp: string (required) — one-time password generated by POST /trading/v1/options/accounts/{accountId}/otp
```

### Response Example

```json
HTTP/1.1 101 Switching Protocols
Upgrade: websocket
Connection: Upgrade

WebSocket connection established successfully.
You can now subscribe to market data and send trading instructions for the demo account.
```

## Status Codes

101 Switching Protocols - WebSocket connection established

400 Bad request

401 Unauthorized - Invalid or missing OTP
